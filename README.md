# Chat Room Realtime Android

Ứng dụng chat realtime được xây dựng bằng Android Studio và Firebase Realtime Database.

## Chức năng

- Đăng nhập
- Danh sách phòng chat
- Gửi tin nhắn realtime
- Nhận tin nhắn realtime

## Công nghệ sử dụng

- Java
- Android Studio
- Firebase Realtime Database
